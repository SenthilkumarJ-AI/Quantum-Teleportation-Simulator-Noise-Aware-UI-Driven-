🚀 What This Project Demonstrates

This simulator shows how an arbitrary quantum state is teleported from one qubit to another using:

Entanglement (Bell pair)

Bell-state measurement

Classical communication

Conditional quantum corrections

Realistic quantum noise (depolarizing error)

🧭 User Experience Flow (Step-by-Step)
Step 1 – Prepare Quantum State

Define an arbitrary quantum state using angles:

θ (theta)

φ (phi)

Step 2 – Add Quantum Noise

Adjustable depolarizing noise

Simulates real NISQ-era quantum hardware

Step 3 – Execute Teleportation

Full teleportation circuit visualization

Choice of circuit rendering:

ASCII

Matplotlib

Step 4 – Analyze Results

Measurement probability histograms

Ideal vs noisy teleportation comparison

Teleportation fidelity calculation
